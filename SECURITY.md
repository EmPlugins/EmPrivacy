# Security Policy

## Reporting a vulnerability

Report a security vulnerability in EmPrivacy (`@emplugins/emprivacy`) through GitHub private vulnerability reporting:

**[Report a vulnerability](https://github.com/EmPlugins/EmPrivacy/security/advisories/new)**

Include the package version, what an attacker can do, and steps to reproduce when you have them. You will get a response on that private advisory. The report stays on the advisory until a fix is published.
